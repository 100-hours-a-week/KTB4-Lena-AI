# 🌍 CLI

> 터미널을 열 때마다, 새로운 여행지와 명언으로 하루를 시작하세요.

<br>

## 💡 아이디어

평소 여행을 좋아해서 만들었어요.  
힘들고 지칠 때 터미널에서 랜덤 여행지와 동기부여 명언을 보며 다시 힘을 낼 수 있도록 기획했습니다.

<br>

## 🚀 사용법

```bash
python cli.py          # 오늘의 여행지 + 명언
python cli.py random   # 랜덤 여행지 + 명언
python cli.py list     # 전체 여행지 목록
```

<br>

## ✨ 주요 기능

- 🗺️ **오늘의 여행지** — 날짜 기반으로 매일 새로운 여행지 추천
- 💬 **동기부여 명언** — 여행과 삶에 관한 명언을 매일 한 가지씩
- 🎲 **랜덤 모드** — 언제든 새로운 여행지를 즉시 만나보기
- 🌈 **컬러 터미널** — 보기 좋은 컬러 출력
