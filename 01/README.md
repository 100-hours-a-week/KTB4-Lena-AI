# 🌍 CLI

> 터미널을 열 때마다, 새로운 여행지와 명언으로 하루를 시작하세요.

<br>

## 💡 아이디어

평소 여행을 좋아해서 만들었어요.  
힘들고 지칠 때 터미널에서 랜덤 여행지와 동기부여 명언을 보며 다시 힘을 낼 수 있도록 기획했습니다.

+) 여행지와 명언 데이터는 LLM에게 달라고 하였습니다.

<br>

## 🚀 사용법

```bash
python cli.py          # 오늘의 여행지 + 명언
python cli.py random   # 랜덤 여행지 + 명언
python cli.py list     # 전체 여행지 목록
```

<br>

## ✨ 주요 기능

- **오늘의 여행지** — 날짜 기반으로 매일 새로운 여행지 추천
- **동기부여 명언** — 여행과 삶에 관한 명언을 매일 한 가지씩
- **랜덤 모드** — 여행지가 랜덤으로 출력
- **컬러** — 컬러 출력

<br>

## 회고
첫 과제여서 처음엔 어떻게 해야할지 막막하기도 하였습니다. 처음에 자주 사용하고 유용한 cli를 만들어야 된다는 생각에 어떠한 아이디어도 내지 못하고 있었는데 오히려 좋아하고 이번 부트캠프 기간동안 저에게 동기부여를 줄 수 있는 주제로 선택하였습니다. 여행을 좋아고 훌쩍 떠나고 싶을 때 자주 찾아보는 사람이기 때문에 힘들때마다 명령어를 불러 저에게 힘을 줄 수 있는 용도로 만들어 보았습니다. LLM의 도움을 결국 받긴 했지만 Alex의 말씀을 듣고 직접 타이핑을 쳐보았습니다. 타이핑을 치다보니 새로운 아이디어도 떠올라 시간이 된다면 리팩토링해보는 것도 좋을 것 같다는 생각을 했습니다.
